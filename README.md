# Talent-to-Business AI Agent

An Agentic AI application that helps skilled women turn their skills into digital businesses.

## Features

- Skill assessment
- Product planning
- Pricing calculation
- Brand ideas
- Digital content
- Marketing planning
- Business roadmap
- Knowledge-base RAG
- SQLite business state
- AI conversational guidance

## Tech Stack

- Python
- Groq
- GPT-OSS-120B
- Streamlit
- SQLite
- RAG

## Deployment

The application can be deployed using Streamlit Community Cloud.

Add the following secret:

GROQ_API_KEY
